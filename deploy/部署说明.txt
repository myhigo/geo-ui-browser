geo-ui-browser 部署包说明
=======================
【电脑环境】
- Docker：
  Windows 装 Docker Desktop（装完打开并保持运行）；
  Linux 装 docker + compose 插件
- 数据库：可访问的 MySQL

========================

1. 把整个 deploy 文件解压到任意目录（路径不要带中文和空格，例如 D:\geo 或 /opt/geo）
2. 调整 geo-ui-env，配置环境变量（至少填上 DB_PASSWORD=数据库密码）
3. 启动：
   - Windows：双击「启动服务.bat」
   - Linux / macOS：在文件夹里打开终端，运行  bash deploy.sh
   第一次运行会自动拉取镜像（约 1-2GB，视网速需要几分钟），之后秒起。

【怎么确认成功了】
- 本机浏览器打开 http://localhost:18787/geoui/admin   （管理台）

【局域网其他人访问】
- 服务已绑定 0.0.0.0，同一局域网（同一 WiFi/交换机）的其他电脑，
  用 http://<这台电脑的局域网IP>:18787/geoui/admin 访问（把 <...> 换成实际 IP，如 192.168.1.5）。
- 查本机局域网 IP：macOS 终端运行  ipconfig getifaddr en0 ；Windows 运行  ipconfig（看 IPv4 地址）。
- 连不上时检查：① 两台电脑在同一网段；② macOS 防火墙放行 Docker 的入站连接
  （系统设置 → 网络 → 防火墙 → 允许 Docker 入站），Windows 检查防火墙是否拦截。
- 注意：管理台无登录口令，开放到局域网后同网段电脑均可访问，请勿把端口暴露到公网。

【常用操作】
- 停止服务：
   Windows 双击「停止服务.bat」；
   Linux 运行  bash stop.sh

【代理 IP（防风控）】
- 新增功能：采集/收录检测统一走代理 IP 池（避免所有请求挤在宿主机 IP 上触发风控）。
- 使用前需在数据库执行一次建表 SQL（新表 + 账号表加列），
  在 MySQL 客户端连上数据库后执行 sql/schema.sql 里新增的部分：
    CREATE TABLE IF NOT EXISTS geo_ui_proxy_ip (...);   -- 见 sql/schema.sql 完整语句
    ALTER TABLE geo_ui_platform_account ADD COLUMN proxy_id BIGINT NULL ...;
  （仓库 sql/schema.sql 里都有现成语句，复制执行即可）
- 使用流程：
  1. 管理台 →「代理管理」→ 添加代理（填 IP:端口，如 1.2.3.4:8080；
     socks5 填 socks5://1.2.3.4:1080，协议自动识别，无需配协议项）
  2. 管理台 →「账号管理」→ 给账号选一个代理 IP（换绑后该账号会自动标记为需重新登录）
  3. 对绑了代理的账号重新登录一次
  4. 跑收录检测 / 信源分析：每个词自动挑一个 IP（最近未用、冷却已过），
     该 IP 下所有平台并行提问；用完后该 IP 冷却 GEO_IP_INTERVAL 秒（默认 120）再轮换。
- 说明：IP 使用后自动冷却轮换（LRU：最早用的先复用）；占用超过 5 分钟未释放（崩溃残留）自动回收；
  已绑定账号的 IP 需先解绑账号才能删除。
